# Plugin Store promo images

Marketing images for the Stop Sign listing on the Craft Plugin Store, in the same theme as the
plugin's page at [justinholt.com/plugins/craft-stopsign](https://justinholt.com/plugins/craft-stopsign).

## Building

```bash
./build.sh          # all slides
./build.sh "3 4"    # just slides 3 and 4
```

Output lands in `out/` as `stopsign-promo-N.jpg`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled). **Promos are JPEG, never PNG** — Chrome can only write PNG, so `build.sh` converts with
`sips` at quality 90 and deletes the intermediate.

On this Mac headless Chrome sometimes exits 2 from its teardown watchdog *after* writing the file,
so `build.sh` judges each slide by whether the PNG exists rather than by Chrome's exit code.

and retake the shots, or the deck quotes a plugin that no longer exists.

## Palette

Accent `#C8102E` from the icon's tile, `#FF6B7D` as the light accent for anything small on the dark
background (the signal red itself is too dark to read as text there), and the family's `#ffd166`
gold. Jersey 20 for display, Inter for body.

## The watermark

`assets/watermark.svg` is the octagon as an **outline** — no tile, no fill, no bar. A filled octagon
at watermark scale is a hard-edged slab, and the bar reads as a UI element. It is turned 22.5° in
CSS: upright, the octagon's left side drew a vertical line straight up every slide and the whole
thing read as a box edge. It is switched off on the cover, where it sat behind the icon.

`assets/icon.svg` is a straight copy of `../src/icon.svg`. Re-copy it whenever the icon changes.

## Screenshots

`shots/` holds four captures from the plugin-testing harness, with a second user ("Dana Reyes",
created for the shoot and deleted after) sending heartbeats with `dirty=1` from curl while the
admin's editor was driven in Playwright:

- `stopsign-banner.png` — full-page editor, 1500 CSS px wide
- `stopsign-guard.png` — the same editor after clicking Save
- `stopsign-slideout.png` — the entries index with the entry open in a slideout, sidebar hidden
- `stopsign-history.png` — the utility at 1100 CSS px, so the tables reflow to a readable width

Other plugins' sidebar blocks and the harness banners were removed from the DOM before capture.
Each slide crops its shot in CSS (`.crop` with `--x --y --w --h`, `--iw` for the capture's width and
`--z` to scale), so a retake never means recutting a PNG.

`fonts.css` is generated by `build.sh` and gitignored; don't edit it.
